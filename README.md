# Servus Credit Union (servus-credit-union)

Servus Credit Union Ltd. is a member-owned cooperative financial institution headquartered in Edmonton, Alberta, founded in 1938. It is Alberta's largest credit union and, following its 2023 member-approved merger with connectFirst Credit Union, became Canada's largest credit union by total assets (roughly $30 billion CAD), serving more than 500,000 members through about 100 branches. Profits are returned to members via the Profit Share program rather than to outside shareholders.

## APIs

Servus Credit Union publishes **no public first-party developer API or developer portal**. Probes of `developer.servus.ca` and `api.servus.ca` do not resolve, and `servus.ca/developer` returns HTTP 404.

Consistent with the honest reality for most Canadian credit unions, external, consumer-permissioned access to member account and transaction data is available only through third-party financial-data aggregators — **Mastercard Open Banking / Finicity** and **Plaid** — not through a first-party API. Canada's federal Consumer-Driven Banking (open-banking) framework, overseen by the Financial Consumer Agency of Canada (FCAC), is legislated but not yet operational, so this aggregator-based, voluntary access model is the current state.

## Open-Finance Posture

- **First-party developer portal:** None (no `developer.*` / `api.*` host resolves).
- **Downloadable OpenAPI/Swagger:** None published.
- **Aggregator access:** Finicity (Mastercard Open Banking) and Plaid, consumer-permissioned.
- **Consumer-Driven Banking (CDB):** Canada's framework is legislated but not yet live; no CDB/FDX endpoint exists.
- **Charter:** Provincially regulated Alberta cooperative (credit union), member-owned.
